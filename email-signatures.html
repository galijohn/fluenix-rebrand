Before rolling this out


  
1 · Move the logos to fluenix.eu

  
They currently load from galijohn.github.io — fine for review, wrong for production. Host them at fluenix.eu/assets/ and replace both src values. If the URL ever dies, every signature already sent turns into a broken-image box.


  
2 · Decide the email domain

  
The template uses @fluenix.eu. If the team stays on @novumglobal.eu, swap it — but then the signature says Fluenix while the address says Novum, which weakens the message.


  
3 · Per-person fields

  
    
    
  • Name and job title
    • 
    
  • Mobile number (both the visible text and the tel: link)
    • 
    
  • Email (both the visible text and the mailto: link)
    • 
  

  
Everything else is identical for the whole team.


  
4 · How to install

  
    
    
  • Gmail: click Copy signature above, then Settings → See all settings → Signature → paste. Do not paste the HTML source — paste the rendered version.
    • 
    
  • Gmail, whole org: Admin Console → Apps → Google Workspace → Gmail → Compliance → Append footer.
    • 
    
  • Outlook desktop: save the HTML source as .htm into %APPDATA%\Microsoft\Signatures, or paste the rendered version into File → Options → Mail → Signatures.
    • 
    
  • Outlook 365, whole org: Exchange admin → Mail flow → Rules → apply disclaimer.
    • 
  


  

    Test before rollout. Send one email to a Gmail address and one to an Outlook desktop address. Outlook renders HTML through Word, not a browser — it is always the one that breaks. This template is built table-based with inline styles specifically for that, but verify it on a real Outlook before the whole team installs it.
