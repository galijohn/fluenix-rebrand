1.2
Identify who hosts fuelomat.cz today — different domain from fluenix.eu, so we need to know where to place the redirect rules. Zjistit, kdo aktuálně hostuje fuelomat.cz — jiná doména než fluenix.eu, takže musíme vědět, kde přesměrování nastavit.
DNS vs. HTTP redirectDNS vs. HTTP přesměrování
  1. Two separate domains — fuelomat.cz and fluenix.eu live on different servers. That's normal for a rebrand.
  2. DNS alone does not redirect — DNS only tells the browser which server to talk to. The 301 redirect happens at the HTTP level, on whichever host serves fuelomat.cz.
  3. Find the current host — log in to the domain registrar (WEDOS or wherever fuelomat.cz is registered) and check the Name Servers. That reveals the hosting provider.
  4. Where the redirect goes depends on the host:
    · Webflow — add fuelomat.cz as an alias in the fluenix.eu project → enable "Domain redirect".
    · WordPress / custom server — Dev adds redirect rules in .htaccess or nginx.conf.
    · Simple registrar redirect — some registrars (WEDOS included) offer a basic "domain forwarding" — not ideal for SEO, but works if nothing else is available.
Do this first — everything in 1.3 depends on knowing where the redirect will live.
  1. Dvě různé domény — fuelomat.cz a fluenix.eu jsou na jiných serverech. Při rebrandu je to standardní.
  2. Samotný DNS nepřesměruje — DNS jen říká prohlížeči, na který server se má obrátit. Samotné 301 přesměrování probíhá na HTTP úrovni, na tom, co obsluhuje fuelomat.cz.
  3. Najít aktuálního hostingu — přihlas se k registrátorovi domény (WEDOS nebo tam, kde je fuelomat.cz registrována) a podívej se na Name Servers. To ti prozradí hostingového poskytovatele.
  4. Kam přesměrování patří podle hostingu:
    · Webflow — přidat fuelomat.cz jako alias v projektu fluenix.eu → aktivovat „Domain redirect“.
    · WordPress / vlastní server — Dev přidá pravidla do .htaccess nebo nginx.conf.
    · Jednoduché přesměrování u registrátora — někteří registrátoři (i WEDOS) nabízejí základní „domain forwarding“ — pro SEO nic moc, ale funguje, když nic jiného nemáš.
Tenhle krok jde první — vše v 1.3 závisí na tom, kde přesměrování poběží.
Dev
1.3
301 redirects live before launch day, tested from Google Search Console. 301 přesměrování naživo ještě před spuštěním, otestováno v Google Search Console.
Step-by-stepKrok za krokem
  1. Dev implements the 301 redirects on the fuelomat.cz server, following the mapping sheet from step 1.1. A "301" is a permanent automatic forwarding rule.
  2. Test each redirect — open httpstatus.io, paste 5–10 old fuelomat.cz URLs. Each must show 301 → 200 at fluenix.eu.
  3. Verify fluenix.eu in Search Console — open search.google.com/search-console → Add property.
  4. Submit "Change of Address" in Search Console (Settings → Change of address) so Google formally transfers rankings from fuelomat.cz to fluenix.eu.
All of this must be green before launch day — not after.
  1. Dev nasadí 301 přesměrování na serveru fuelomat.cz podle mapy z kroku 1.1. „301“ je trvalé automatické přesměrování.
  2. Otestuj každé přesměrování — otevři httpstatus.io, vlož 5–10 starých URL fuelomat.cz. U každé se musí zobrazit 301 → 200 na fluenix.eu.
  3. Ověř fluenix.eu v Search Console — otevři search.google.com/search-console → Přidat property.
  4. Podej „Change of Address“ v Search Console (Nastavení → Změna adresy), aby Google formálně přenesl pozice z fuelomat.cz na fluenix.eu.
